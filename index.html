Project Overview

The Student Record Management System (SRMS) is a comprehensive console-based application conceptualized in C language. It serves as a digital solution to replace manual record-keeping, demonstrating efficient file handling, procedural programming, and role-based access control (RBAC) in a real-world educational scenario.

Key Features

  • RBAC Security

    Secure logins for Admin, Staff, Guest.

  • File Persistence

    Data stored permanently in text files.

Tech Stack (Simulation)

  • C Language

    Logic implemented via procedural code.

  • File I/O

    fopen, fprintf, fscanf operations.
