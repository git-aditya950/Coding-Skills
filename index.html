Project Documentation

Project Overview

The Student Record Management System (SRMS) is a console-based application conceptualized in C language for managing student academic records efficiently. It allows authorized users (Admin, Staff, Guest) to manage student data using file handling and role-based access control (RBAC).

Key Features

  • Role-Based Login: Secure access for Admin, Staff, and Guest.
  • File-Based Storage: Persistent data storage in students.txt.
  • CRUD Operations: Create, Read, Update, Delete records.
  • Secure Updates: Uses temporary files for data integrity during updates.

Technologies Used

  • Language: C Programming
  • Concepts: File Handling (fopen, fprintf), Structures, Pointers
  • Logic: Procedural Programming, Authentication Logic

System Workflow

1. Login (credentials.txt) -> Validate Role
2. Admin Menu -> Add/Edit/Delete/Search/View
3. Staff Menu -> Add/Edit/Search/View
4. Guest Menu -> Search/View
5. Data Operations -> Modify students.txt
